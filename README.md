# Portfolio — Marie A. A. Sène (CookieKOD)

Site statique (HTML/CSS/JS, aucune dépendance, aucun build).

## Modifier le contenu
Tout le texte est dans `data.js` : projets, compétences, parcours, liens.
- Ajoutez votre e-mail dans `links.email`.
- Pour le CV : déposez `cv.pdf` dans ce dossier et mettez `cv: "/cv.pdf"`.
- Pour une démo en ligne d'un projet : ajoutez `demo: "https://..."` au projet.

## Tester en local
Ouvrez `index.html` dans le navigateur.

## Déployer gratuitement

**Vercel** : créez un dépôt GitHub (ex. `portfolio`), poussez ces fichiers,
puis sur vercel.com → Add New → Project → importez le dépôt → Framework : *Other* → Deploy.

**GitHub Pages (alternative)** : nommez le dépôt `cookieKOD.github.io`, poussez les fichiers,
le site sera en ligne sur https://cookiekod.github.io.

**Netlify (alternative)** : glissez-déposez le dossier sur app.netlify.com/drop.
